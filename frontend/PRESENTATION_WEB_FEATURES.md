# 발표용 웹 기능 목록

## 1) 전장 지도/상황 인식
- 실시간 전장 지도 렌더링(기본맵/레이어 표시 제어)
- 적/우군/중립 객체 시각화(심볼, 라벨, 상태 정보)
- 좌표 표시(MGRS, 위경도) 및 객체 선택 상세 패널
- 시나리오 단계별(탐지→판단→대응) 지도 상태 전환

## 2) SAR(위성) 기반 탐지 기능
- ScanSAR 광역 탐지 구역 표시 및 테두리 호버 정보
- SAR Spotlight 정밀 탐지 구역 포커스 이동
- SAR 기반 적 이동 확률/방향/도달 목표 시각화
- SAR 탐지 결과 팝업/모달(이미지, 요약 정보)

## 3) GRD 이동 검출 기능
- GRD 이동 검출 폴리곤(전차/일반차량) 시각화
- 검출 후보 클릭 시 표적 정보 및 출동 추천 연계
- 파란 검출(일반차량) 클릭 시 SAR 변화검출 이미지 우선 노출
- 겹침 상황에서 적 표적 우선 클릭 처리

## 4) UAV/드론 출동 의사결정
- 표적별 UAV 출동 추천(거리, ETA, 준비태세 기반)
- 추천 후보 비교 선택(단일 선택/추천 강조)
- 하단 액션(움직임 감지, 취소, UAV 출동) 즉시 실행
- 출동 후 표적 추적 상태 표시 및 미션 연동

## 5) 대응 전술/시뮬레이션
- 적 표적 대상 대응 전술 선택(다중 전술 선택 가능)
- 전술 점수/근거 제시 및 적용 결과 반영
- 탐지 단계별 이미지/영상 재생 모달
- 시나리오 진행 중 경고/알림 패널(긴급 이벤트 표시)

## 6) 사용자 인터랙션/UX
- 객체 호버 툴팁/클릭 팝업(상황별 내용 분기)
- 지도 포커스 이동 후 후속 액션(예: 팝업 재생) 연동
- 모달 탭 전환(탐지 화면 ↔ 출동 추천 화면)
- 모바일/소형 화면 대응 레이아웃(푸터/버튼 정렬 포함)

## 7) 데모 강조 포인트(발표 멘트용)
- "탐지(센서) → 판단(분석) → 대응(출동)" 전 과정이 한 화면에서 연결됨
- SAR/GRD/UAV 기능이 독립이 아니라 이벤트 기반으로 자연스럽게 이어짐
- 클릭 우선순위, 포커스 이동, UI 전환 등 실제 운용 흐름에 맞춘 사용자 경험
